# PDF Converter 📄🖼️

Зручний інструмент на Python для конвертації документів Word та зображень у PDF.

## 🚀 Можливості
- **Word -> PDF**: Швидке перетворення `.docx` та `.doc` у PDF.
- **Зображення -> PDF**: Об'єднання кількох зображень (`JPG`, `PNG`, `WEBP` тощо) у єдиний PDF.
- **Сортування**: Можливість змінювати порядок сторінок/зображень перед створенням PDF.
- Автоматичне збереження з датою та часом у назві.
